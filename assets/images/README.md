# Assets Directory

## Images

Place images here for use on the website.

### Recommended Files

- `favicon.png` - Site favicon (32x32 or 48x48 pixels)
- `logo.png` - Organization logo
- `og-image.png` - Open Graph image for social media (1200x630 pixels)

### Image Guidelines

- Use WebP format when possible for better compression
- Provide alt text for all images
- Optimize images before uploading
- Use descriptive filenames (e.g., `spurs-building-front.jpg`)
- Keep file sizes reasonable (< 500KB for photos)

### Tools for Image Optimization

- [TinyPNG](https://tinypng.com/)
- [Squoosh](https://squoosh.app/)
- [ImageOptim](https://imageoptim.com/)
